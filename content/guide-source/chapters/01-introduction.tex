\section{What the \appname{} is}

The \appname{}\index{e-CALLISTO FITS Analyzer} is a cross-platform desktop application for
visualizing, processing and analyzing solar radio dynamic spectra recorded in FITS format
by the e-CALLISTO spectrometer network, and for placing those observations in their solar
and geophysical context. It runs natively on Windows, macOS and Linux (Debian and Ubuntu)
and is distributed as self-contained installers, so no separate Python installation is
required.

e-CALLISTO\index{e-CALLISTO network} is a world-wide network of CALLISTO radio
spectrometers that monitors the Sun around the clock \parencite{benz2009}. Each station
records dynamic spectra --- radio intensity as a function of frequency and time --- in
FITS files that normally span 15~minutes. A station may operate several receivers or
frequency bands, each identified by a two-digit \emph{focus code}\index{focus code}. File
names follow the pattern
\file{STATION_YYYYMMDD_HHMMSS_FC.fit.gz}, for example
\file{Australia-ASSA_20261004_000000_63.fit.gz} for focus code~63 of the Australia-ASSA
station starting at 00:00:00~UT on 4~October~2026.

The application merges fragmented observations across time and frequency, removes the
receiver background, mitigates radio-frequency interference (RFI)\index{RFI}, and isolates
solar radio bursts with an interactive mask. Dedicated tools derive the frequency drift
rate and shock parameters of Type~II bursts and estimate the coronal magnetic field\index{magnetic field} from
band-split emission. Around this core, the software retrieves archive data from several
radio instruments, displays X-ray, particle, geomagnetic and coronal mass ejection (CME)
data for the same interval, analyzes solar images from space-borne observatories, models
the coronal magnetic field, and reconstructs CMEs in three dimensions. It follows an event to
Earth with its geomagnetic response, draws the flare, CME and storm catalogs beside the
spectrum, composes a figure of the whole event, and keeps the radio, solar-image and CME work
of one event in a single project file.

\section{Workflow overview}

Figure~\ref{fig:workflow} shows how the main components relate to each other. Data enter
the main window from local files, the downloaders or a saved project; they are processed
in the sidebar; analysis windows take the processed spectrum as input; and every stage can
be saved in a project or exported. The context and imaging tools can be synchronized to
the time window of the loaded spectrum, and the event-context tools follow the event time
of the loaded data.

\section{What is new in version \appversion}
\label{sec:whats-new}

Version~\appversion{} turns a radio burst into the story of a whole event. It adds or
substantially extends the following features, all of which are described in this guide:
\begin{itemize}
  \item \textbf{One project for every window:} a single \file{.efaproj} file holds the radio
    analysis, the Solar Image Analysis frames and measurements, and the GCS fits, with the
    images linked or embedded (Section~\ref{sec:projects});
  \item \textbf{Geomagnetic Response:} Dst, SYM-H, Kp, the IMF, solar wind and auroral indices
    from one day before to seven days after the event, as a sidebar card and a window
    (Section~\ref{sec:geomagnetic-response});
  \item \textbf{Event Context Strip and Event Figure:} flare, CME, DONKI and burst catalogs
    above the spectrum, and one composed publication figure of the event
    (Sections~\ref{sec:event-strip} and~\ref{sec:event-figure});
  \item \textbf{Project reports} that open with an Event Story and include Solar Image Analysis
    and GCS sections (Section~\ref{sec:project-report});
  \item \textbf{Solar Image Analysis:} a choice of full-resolution FITS, reduced-size FITS or
    JPEG2000 quicklook products, download progress based on the real transfer, the AIA~193~Å
    Sun in LASCO's occulter, and labelled north-up movies
    (Chapters~\ref{ch:solar-window} and~\ref{ch:solar-processing});
  \item \gui{Reset All}, which returns the application to its start-up state
    (Section~\ref{sec:toolbar}).
\end{itemize}
Version~3.1.0 introduced ridge tracking, the selectable power-law time origin and density
models, the \gui{Timeline} panel, the logarithmic frequency axis, the \gui{Burst List}\index{FITS Downloader!Burst List},
PFSS modeling and GCS fitting\index{GCS!fitting report}; they are described in the chapters concerned.

\begin{caution}
  Projects saved by version~\appversion{} cannot be opened by version~3.1. Keep a copy of any
  project you still need to open in version~3.1 before saving it again. Version~3.1 radio
  projects open unchanged, and a version~3.1 \file{.ecsolar} Solar Image Analysis session
  opens as a new, unsaved project.
\end{caution}
